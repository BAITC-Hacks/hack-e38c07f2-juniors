# SmartFlow — работа команды из трёх человек

Базовый MVP SmartFlow уже объединяет все экраны. Чтобы избежать конфликтов, распределите дальнейшую работу по файлам.

| Участник | Ответственность | Файлы |
|---|---|---|
| 1 | UI, тексты, адаптивность, ручная проверка пути | public/ |
| 2 | API, рейтинг, AI, валидация | server.js, lib/domain.js, tests/ |
| 3 | Демо-данные, README, репетиция и сдача | lib/seed.js, README.md, DEMO.md |

Сначала все запускают SmartFlow и проходят DEMO.md. Затем назначьте одного ответственного за интеграцию. Не меняйте одновременно один файл. API-ключи вводите в собственный `.env`; не отправляйте их в чат, README или Git.

Приоритет перед сдачей: реальный AI-вызов → полный ручной сценарий → тесты → актуальная версия в GitHub → отправка решения на платформе. Ссылку на GitHub в форме сдачи отправляет участник с доступом к платформе.
