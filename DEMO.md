# Демонстрация SmartFlow

Сценарий защиты проекта команды **Juniors** на HackAlem AI.

**Продолжительность: до 5 минут.**

Цель — показать работающий путь от слабого описания задачи до публикации, предложения команды и решения бизнеса.

## Подготовка

1. Запустить SmartFlow:

   ```bash
   node --env-file=.env server.js
   ```

2. Открыть `http://localhost:3000`.
3. Проверить настоящий AI-запрос.
4. Выбрать русский язык и петрольную тему.
5. Подготовить тексты из таблиц ниже для быстрого ввода.
6. Запустить тесты:

   ```bash
   node --test
   ```

7. Открыть README и репозиторий в отдельных вкладках.

Не показывать `.env` и API-ключ во время защиты.

Если OpenAI недоступен, честно показать резервный режим и продолжить основной сценарий.

## Распределение выступления

| Участник | Часть демонстрации |
|---|---|
| Первый | Проблема, создание задачи и AI-вопросы |
| Второй | Карточка, рейтинг, каталог и предложение |
| Третий | Решение бизнеса, прогресс и дополнительные функции |

Для экономии времени управлять приложением может один человек.

## 0:00–0:25 — Проблема и решение

### Сказать

> Бизнесу бывает сложно сформулировать задачу для студентов. Описания «хотим улучшить закупки» недостаточно: неизвестны данные, ограничения и критерии результата.
>
> SmartFlow помогает уточнить задачу. Чем полнее бизнес заполняет и подтверждает сведения, тем выше рейтинг готовности. Команды выбирают проекты самостоятельно.

### Показать

Каталог, рейтинги карточек и кнопку создания задачи.

## 0:25–1:05 — Слабое описание

### Действия

1. Нажать «Создать задачу».
2. Нажать «Подставить пример».
3. Показать описание:

   > У нас кофейня. Иногда не хватает молока, а выпечку приходится списывать. Хотим лучше планировать закупки.

4. Показать рейтинг **0/100**.
5. Нажать «Получить уточняющие вопросы».

### Сказать

> SmartFlow помогает обнаружить пробелы. AI задаёт вопросы, но не придумывает факты о компании. Сведения вводит и подтверждает бизнес.

### Ожидаемый результат

Появляются 3–5 вопросов. Их формулировки могут меняться при каждом запросе.

## 1:05–2:10 — Карточка и рейтинг

### Действия

1. Ответить минимум на три вопроса.
2. Нажать «Перенести ответы в карточку».
3. Дополнить поля подготовленными сведениями.
4. Подтверждать поля последовательно и показывать рост рейтинга.

### Подготовленный пример

Все сведения ниже синтетические.

| Поле | Ответ |
|---|---|
| Контекст | Остатки записывают вручную. Иногда молоко заканчивается до конца смены, а непроданную выпечку приходится списывать. |
| Потребность | Прогнозировать закупки на неделю, чтобы уменьшить нехватку ингредиентов и списания. |
| Данные | Обезличенный CSV продаж за три месяца и таблица закупок. |
| Результат | Веб-прототип с загрузкой CSV и рекомендациями закупок на неделю. |
| Критерии успеха | Ошибка прогноза не выше 20% на отложенной тестовой выборке. |
| Ограничения | Прототип за 14 дней, без подключения к кассе и без персональных данных покупателей. |
| Пользователи | Управляющий и бариста небольшой кофейни. |
| Контакт | demo@coffee.example |
| Взаимодействие | Управляющий доступен дважды в неделю по 30 минут, даёт обратную связь и принимает результат. |

### Контрольные значения

- Контекст + потребность + данные → **40 баллов**.
- Дополнительно результат + критерии успеха → **70 баллов**.
- Все поля → **100 баллов**.

### Сказать

> Рейтинг SmartFlow прозрачен: видно, какое поле приносит баллы. Он отражает заполненность подтверждённых сведений, а не известность компании.
>
> За достоверность содержания отвечает бизнес.

Если позволяет время, изменить подтверждённое поле: его баллы снимаются до повторного подтверждения.

## 2:10–2:40 — Публикация

### Действия

1. Отметить подтверждение публикации.
2. Нажать «Опубликовать задачу».
3. Вернуться в каталог.
4. Найти созданную карточку.

### Сказать

> Задача получила приоритетный уровень готовности и опубликована. Каталог сортируется по рейтингу.
>
> Низкий рейтинг не скрывает опубликованную задачу и не запрещает отклики.

### Ожидаемый результат

Карточка присутствует в каталоге с рейтингом **100/100**. При наличии других задач с таким рейтингом она может находиться рядом с ними.

## 2:40–3:20 — Предложение команды

### Действия

Открыть карточку и заполнить предложение:

| Поле | Значение |
|---|---|
| Команда | Juniors |
| Идея | Построим прогноз спроса по истории продаж и покажем рекомендации закупок в веб-панели. |
| План | Проверим CSV, построим базовый прогноз, создадим интерфейс и оценим точность на тестовой выборке. |
| Срок | 14 дней |
| Прототип | https://example.com/coffee-demo |

Нажать «Отправить предложение».

### Сказать

> Команда самостоятельно выбрала задачу и предложила подход, план и срок. SmartFlow не назначает исполнителей автоматически.
>
> В этом примере ссылка демонстрационная. В реальном отклике команда указывает свой прототип.

### Ожидаемый результат

Появляется сообщение об отправке, количество предложений увеличивается.

## 3:20–4:00 — Выбор бизнеса и прогресс

### Действия

1. Нажать «Посмотреть отклики как бизнес».
2. Найти предложение Juniors.
3. Нажать «Выбрать команду».
4. Показать новый статус.

### Сказать

> Бизнес принимает решение самостоятельно. Можно выбрать одну, несколько или ни одной команды. Другие предложения не отклоняются автоматически.

Затем обозначить условный переход во времени:

> Предположим, команда завершила прототип, а заказчик проверил результат. Теперь бизнес подтверждает этап.

5. Подтвердить завершение этапа.
6. Открыть раздел «Команды».

### Ожидаемый результат

Juniors получает **+10 баллов** к предыдущему результату. Повторное подтверждение того же этапа не увеличивает баллы.

Не утверждать, что реальная работа была выполнена во время защиты.

## 4:00–4:35 — Помощник, языки и темы

### Действия

1. Открыть AI-помощника SmartFlow.
2. Отправить:

   > Какие сведения помогут бизнесу лучше подготовить задачу для студентов?

3. Показать ответ.
4. Закрыть чат.
5. Переключить интерфейс на KZ или EN.
6. Выбрать Сливу или Терракоту.

### Сказать

> Встроенный помощник SmartFlow работает через OpenAI и помогает уточнять задачи. Он не публикует карточки и не принимает решения вместо пользователя.
>
> Интерфейс доступен на трёх языках. Язык и тема сохраняются в браузере. Тексты самих задач остаются на исходном языке.

Если ответ AI задерживается, показать настройки и затем вернуться к диалогу.

## 4:35–5:00 — Техническая часть

### Действия

1. Обновить страницу и показать сохранённые тему и язык.
2. Кратко показать README и результат тестов.

### Сказать

> SmartFlow запускается на Node.js без установки сторонних зависимостей. Задачи, предложения и решения сохраняются в JSON-файле.
>
> Тесты проверяют рейтинг, основной сценарий, сохранность данных и валидацию чата.
>
> Это MVP без авторизации и разграничения доступа. При этом путь от описания проблемы до выбора команды работает в приложении.

## Резервный сценарий без внешнего AI

1. Показать сообщение о локальном режиме.
2. Продолжить заполнение карточки с резервными вопросами.
3. Продемонстрировать публикацию, отклик и выбор команды.
4. При необходимости показать:
   - `lib/domain.js` — промпт и проверка вопросов;
   - `lib/assistant.js` — правила помощника;
   - `tests/assistant.test.js` — проверки истории и локальных ответов.

### Сказать

> Внешний AI сейчас недоступен. SmartFlow явно сообщает об этом и использует резервную логику. Основной сценарий продолжает работать.

## Ключевые акценты

- Геймификация помогает бизнесу подготовить задачу.
- Каждое начисление баллов объяснимо.
- Низкий рейтинг не блокирует опубликованные задачи.
- Студенты самостоятельно выбирают проекты.
- Бизнес вручную выбирает команды.
- Сведения и публикацию подтверждает человек.
- Баллы команды связаны с подтверждённым этапом.
- Основные переходы показаны в работающем приложении.
